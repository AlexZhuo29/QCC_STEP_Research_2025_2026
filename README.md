# QCC_STEP_Research_2025_2026
This repository contains the code for the research conducted by Alex Zhuo and Tasmin Jannat. This research is on the hyper tuning of classical machine learning algorithm K Nearest Neighbors in Python in order to improve the prediction accuracy on the stock market.
